# RED FLAG DETECTOR

一款戀愛情境選擇遊戲。

妳會遇到各種約會、曖昧、交往與突發狀況。沒有標準答案，請照妳真的會做的方式選。

## 🎮 開始遊戲

**遊戲網址：**  
https://lancer1234.github.io/RED-FLAG-DETECTOR/

建議使用手機或直向畫面遊玩。

第一次開始遊戲時，會先出現 3 張簡短玩法說明。之後也可以在開始畫面按 **玩法說明 / HOW TO PLAY** 再看一次。

## 遊戲模式

開始時可以選擇兩種長度：

- **FULL SCAN**：20 張卡
- **LONG SCAN**：50 張卡

每一局的內容都會重新抽取，因此重玩時可能遇到不同的情境與發展。

## 怎麼玩

閱讀畫面上的情境後，選擇最接近妳真實反應的答案。

一般情況會有：

- **A**
- **B**
- **C**

遊戲進行中，有時也可能出現額外選項。

電腦可以直接使用鍵盤 **A / B / C / D** 作答；手機則直接點擊選項。

選擇之前不會顯示該答案會怎麼影響數值。選下去之後，系統才會公布這次選擇造成的變化。

## 四項數值

遊戲上方會持續顯示四項狀態：

- **LOVE** — 心動與感情投入程度
- **RADAR** — 對細節、矛盾與警訊的敏感度
- **STANDARD** — 自己的界線與關係標準
- **CHAOS** — 冒險、戲劇性與衝動程度

每次選擇都可能同時影響不只一項數值。

不要刻意追求某一條越高越好，依照自己的直覺玩即可。

## TONIGHT MODIFIER

每一局開始時，畫面上方可能出現一個 **TONIGHT MODIFIER**。

它代表這一局的特殊狀態，可能讓某些選擇造成的影響和平常不同。

所以即使再次遇到類似情況，同樣的玩法也不一定會得到完全相同的局勢。

## 連續情境

有些情境不是獨立事件，可能在幾題之後再次出現後續。

如果前後間隔較久，畫面會出現：

**PREVIOUSLY ON // 上回提要**

用來提醒妳之前發生了什麼，以及當時做過什麼選擇。

## 人物回覆

部分選擇完成後，不會立刻跳到下一題。

對方可能會先做出回應，或出現一小段後續發展。

看到回覆後，按下 **繼續 / CONTINUE** 才會進入下一張卡。

電腦也可以使用 **Enter** 或 **空白鍵** 繼續。

## EVENT CARD

遊戲途中可能出現 **EVENT CARD**。

這類卡片代表突發狀況，不一定屬於正在互動中的某一個人，但妳的處理方式仍會影響整局狀態。

偶爾也可能遇到調性較嚴肅的特殊事件。這類卡片會用不同標示呈現，請依照當下情境選擇妳真正會採取的處理方式。

有些事情也可能在後面的情境再次被提起，所以前面的選擇不一定答完就完全消失。

## 關係狀態與個人傾向

遊戲會記住妳在這一局做過的部分選擇。

隨著遊戲進行，畫面偶爾可能顯示：

- **RELATIONSHIP STATE** — 目前這段互動的變化
- **TRAITS** — 系統逐漸觀察到的作答傾向
- **CROSS FILE** — 前面某件事情再次影響目前情境

遊戲結束後，也可能看到 **RELATIONSHIP PATTERN // 關係傾向**。這一區會根據本局部分情境整理出親密焦慮、親密迴避、界線清晰與衝動決策等參考傾向。

這些數值只用來幫助自我觀察，不是心理診斷，也不是正式心理量表的分數。畫面會同時顯示本局累積到多少個校準情境，以及目前的參考度。

## DETECTED FILES

開始畫面與遊戲結束後都可以開啟：

**DETECTED FILES // 已偵測檔案**

這裡會保存妳實際在遊戲中遇過的內容與收集進度。

紀錄只儲存在目前使用的瀏覽器中，不需要登入帳號。

## 遊玩建議

第一次玩時，不需要研究系統或刻意控制數值。

**把它當成朋友丟給妳一堆感情問題，選妳第一時間真的會做的事就好。**

重玩時，才會慢慢發現不同選擇、不同狀態和前面發生過的事情，可能讓後續出現不一樣的變化。
